# Frontend (React + Vite + TypeScript)

This is the frontend for the Job Portal project.

## Setup

```bash
cd Frontend
npm install

cp .env.example .env
npm run dev
```

Vite will print the local URL (usually `http://127.0.0.1:5173`). If that port is busy, it will use the next one.

## Environment

Required:
- `VITE_API_BASE_URL` (example: `http://127.0.0.1:5000/api`)

Optional:
- `VITE_APP_NAME`

## Build

```bash
npm run build
```
